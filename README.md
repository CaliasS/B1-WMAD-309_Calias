# 🪳 Kill the Cockroaches! – A PWA Game

A fun, progressive web game where your mission is to kill as many cockroaches as possible using a slipper! Built with vanilla HTML, CSS, and JavaScript. Fully installable as a PWA and works offline.

## 🎮 Features

- 🖱️ Custom slipper cursor
- 🔊 Background music & squash sound effect
- 🕐 Timer & kill counter
- ⚡ Cockroach speed increases every 10 seconds
- 📴 Offline detection
- 📲 Installable as a Progressive Web App (PWA)
- 🪳 Cockroaches animate and die with a graphic
- 📱 Fully responsive and mobile-friendly

## 🧩 PWA Support

- The game includes a `manifest.json` and a `service-worker.js` to support offline access and installation.
- When opened in a browser, users can install it to their home screen or desktop.
